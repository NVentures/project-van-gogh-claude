## Lessons

- A vendor's `--json` reply is a capture, not a guess: Codex pretty-prints over many lines, a line-based parser read it as empty and graded a clean install as an error while a `json.dumps` stub stayed green. Fixtures now carry the captured shape (lab-notes CODEX HEADLESS).
- A plugin update deletes the folder the updating script imports from; import everything the post-step needs before spawning the client (lab-notes CODEX HEADLESS).
- A marker-delimited block in a file another program also writes needs two defences: carve out what that program appends inside the markers, and find the block by its content when the program drops a marker (lab-notes CODEX HEADLESS).
- A test that runs a shell script pins `SHELL`; bash fills an unset one from the login shell, which differs between this Mac and the macOS CI runner (lab-notes SHELL IS NOT THE SHELL YOU TESTED IN).
- A cold-read loop re-renders its input immediately before every round and files every round's report; the /objective skill now says so (task-observer #125).
- A frozen verify step can name something the client does not do (`prompt-input` never expands a mention; the model recovers a path without the env key): re-open with the owner, never implement around it (lab-notes THIRD-PARTY DELAY IS NOT A CLASS DISCRIMINATOR, same shape).
- A read-only sandbox plant must tell the model the failure is the expected outcome and grade on a command item, because the model is told the sandbox is read-only and declines on its own in 2 of 8 runs (lab-notes CODEX HEADLESS).
- A live fixture placed at now plus two hours lands on tomorrow after 10 PM PT / 1 AM ET and a today filter drops it; place today's fixtures by date (lab-notes TEST ISOLATION LEAKS, MIDNIGHT twin).
- Every live script answers --help without running; an evaluator probing usage ran a full mutation matrix and wrote a file named --help (fixed in all eight scripts).
